[입력 근거 조건: {evidence_mode}]

아래 원격탐사 sample에 대해 유용한 시각 질의응답(VQA) 객체를 정확히 4개 생성하라.

규칙:
- 모든 판단에서 제공된 한국어 description을 사용한다. RGB image가 첨부된 경우 이는 HSI에서 추출한 RGB 표현이며 raw hyperspectral cube가 아니다.
- 질문, 답변, 근거를 모두 자연스러운 한국어로 작성한다. JSON key와 question_type 값만 아래 schema의 영문 표기를 유지한다.
- 각 질문은 서로 달라야 하며 제공된 근거만으로 답할 수 있어야 한다.
- description에 명시된 경우에만 분광 또는 재질 정보를 사용한다. RGB만 보고 보이지 않는 파장대나 확정적인 재질 정체를 추론하지 않는다.
- 답변은 장황한 설명 대신 짧고 구체적으로 작성한다.
- evidence에는 답을 뒷받침하는 description 또는 RGB의 사실을 간결한 한국어로 작성한다.
- 타당한 범위에서 question_type을 spatial, counting, comparison, attribute, interpretive 중 다양하게 사용한다.
- 이 prompt, 입력 근거 조건, 제공되지 않은 입력을 언급하지 않는다.
- text-only 조건에서는 image, 영상, 사진, RGB를 직접 보았다고 표현하지 않는다.

설명문 없이 JSON 객체 하나만 반환하라:
{{"pairs":[{{"question":"...","answer":"...","evidence":"...","question_type":"spatial"}}]}}

Paired HSI-derived source description (한국어):
{description}
